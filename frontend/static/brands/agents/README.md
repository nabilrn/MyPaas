# AI coding agent logo assets

The monochrome logo sprite in this directory is vendored locally so the MyPaaS UI does not hotlink third-party assets.

The logo paths for Codex, Claude, GitHub Copilot, Cursor, Windsurf, Cline, Gemini, Replit, OpenCode, and Roo Code were sourced from the MIT-licensed `lobehub/lobe-icons` project (`packages/static-svg/icons/*`) and normalized into one `currentColor` SVG sprite for MyPaaS.

These marks identify popular AI coding agents/tools shown as ecosystem examples. Their appearance in MyPaaS does not imply endorsement, partnership, or that every product exposes the same MCP capabilities.
