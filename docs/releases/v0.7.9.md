# MyPaaS v0.7.9

**Release type:** Stable patch release  
**Release date:** 2026-10-02  
**Release tag:** `v0.7.9`

`v0.7.9` fixes Host resources history continuity when the dashboard tab is hidden or left idle and then reopened.

## Highlights

### Hidden-tab continuity

- Returning to the dashboard no longer injects a synthetic all-null telemetry sample.
- Failed host-stat polls no longer create fake blank slots in rolling history.
- The rolling chart remains continuous across periods where the browser collected no samples.

### Correct cumulative counter handling

- CPU and Network cumulative baselines are preserved across browser collection pauses.
- The next successful CPU sample derives usage from the real cumulative counter delta.
- The next successful Network rate uses the actual elapsed time between successful counter snapshots.
- Existing counter-reset and interface-change safeguards remain intact.

### Telemetry contract

- Successful snapshots with no usable host telemetry are skipped instead of appended as all-null history rows.
- The frontend HostStats contract now includes backend `telemetry_status` and `telemetry_error_code` fields for future diagnostic use.
