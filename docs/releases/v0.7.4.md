# MyPaaS v0.7.4

**Release type:** Stable patch release  
**Release date:** 2026-10-01  
**Release tag:** `v0.7.4`

`v0.7.4` is a focused telemetry-visualization patch for the Host resources chart.

## Highlights

### Aligned chart window

- Memory, CPU, and Network now begin from a common valid chart window instead of exposing the baseline-building gap from the first CPU/network counter sample.
- Leading bootstrap-only samples are trimmed from the rendered history; genuine missing telemetry later in the series remains visible as a gap.
- Chart x positions are derived from actual sample timestamps rather than assuming perfectly uniform polling intervals.
- Pointer hover selects the nearest timestamp-derived sample instead of using a fixed index ratio.

### Improved network scale

- Network traffic remains zero-anchored.
- The upper bound is padded with readable headroom so observed peaks do not touch the top edge.
- Bursty network traffic uses a bounded power transform derived from the observed distribution, keeping normal activity readable without clipping spikes.
- The right-side network scale exposes the transformed midpoint as well as minimum and maximum values.
- Memory and CPU continue to use their physical 0–100% scale.

### Regression coverage

- Added tests for the aligned history window and timestamp-based spacing.
- Added tests for the adaptive network rate scale, zero anchoring, headroom, and bounded burst compression.
