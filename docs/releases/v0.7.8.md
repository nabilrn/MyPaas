# MyPaaS v0.7.8

**Release type:** Stable patch release  
**Release date:** 2026-10-01  
**Release tag:** `v0.7.8`

`v0.7.8` fixes Host resources history fragmentation caused by polling jitter.

## Highlights

### Stable rolling host history

- The Host resources chart no longer infers visual discontinuities from irregular request timing.
- Rolling samples remain evenly spaced.
- Memory, CPU, and Network paths now break only when the series contains an explicit missing telemetry sample.
- Ordinary request latency or polling jitter no longer creates repeated white gaps, isolated points, or fragmented area fills.

### Explicit missing telemetry handling

- A real browser collection pause records one explicit all-null history gap.
- A failed host telemetry request records an explicit history gap while preserving the last known live summary.
- CPU and Network cumulative baselines reset after known collection gaps so the next derived rate is not averaged across unsampled time.
- Existing adaptive Network Y scaling, aligned bootstrap start, hover timestamps, and Storage capacity behavior are preserved.
