# MyPaaS v0.6.0-rc.11

## Included changes

- Rebuilds the installation wizard as a full MyPaaS workspace with focused Domain, GitHub, Cloudflare, and Review steps plus a dedicated backup-restore flow.
- Hardens installer restore and setup handling with token-protected uploads, bounded streaming, strict archive validation, safer secret handling, and atomic restore promotion.
- Adds live Domain, GitHub, and Cloudflare preflight qualification and gates setup progression on successful checks.
- Binds first owner authorization to GitHub's verified primary email and keeps the durable account binding on GitHub's numeric user ID afterwards.
- Aligns installer layout, copy, controls, and responsive behavior with the authenticated MyPaaS workspace contract.
- Lowers the Static/no-runtime resource-profile CPU floor from 0.10 to 0.01 core across backend validation, Administration settings, project creation, and project settings fallbacks.

## Qualification focus

Upgrade from rc.10 and confirm:

- the installer uses the full MyPaaS workspace flow and backup restore dropzone;
- Domain, GitHub, and Cloudflare preflight gates behave correctly without exposing credentials;
- existing owner authentication still succeeds with the durable GitHub identity binding;
- Administration Settings accepts `0.01` CPU for the Static profile;
- new static projects inherit the configured `0.01` Static CPU default;
- values below `0.01` are rejected;
- Go, Node/Python, Compose, and custom resource behavior remains unchanged;
- the dashboard reconnect/update flow remains functional when moving from rc.10 to rc.11.
