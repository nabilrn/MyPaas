# MyPaaS v0.7.5

**Release type:** Stable patch release  
**Release date:** 2026-10-01  
**Release tag:** `v0.7.5`

`v0.7.5` fixes Host resources chart continuity after browser-background telemetry pauses.

## Highlights

### Stable rolling chart geometry

- Restored uniform rolling-sample spacing across the Host resources history chart.
- The chart no longer stretches wall-clock pauses into large horizontal gaps after returning to a previously hidden tab.
- The common aligned start window from `v0.7.4` is preserved, so Memory, CPU, and Network still begin from the same valid sample window.

### Telemetry discontinuity handling

- MyPaaS now derives the expected telemetry cadence from observed sample intervals while excluding slow outliers from the cadence estimate.
- Intervals above `2.5 ×` the stable cadence are treated as real telemetry discontinuities.
- Line and area paths break across those discontinuities instead of drawing synthetic continuity through periods with no samples.
- Samples adjacent to a discontinuity can still render as isolated points.
- Exact sample timestamps remain available in hover inspection.

### Scope

- Frontend-only change.
- No backend API, mypaas-statd, polling interval, layout, color palette, or network Y-scale contract changes.
