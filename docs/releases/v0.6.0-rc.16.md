# MyPaaS v0.6.0-rc.16

## Included changes

- Clarifies Administration resource-profile CPU fields as `CPU Limit` so the UI no longer implies dedicated or reserved CPU allocation.
- States explicitly that profile CPU values are per-project limits and that CPU remains shared across projects.
- Keeps host-capacity copy aligned with shared-CPU semantics while noting that per-project CPU limits remain enforced.
- Fixes capacity-chart helper text so explanatory copy wraps instead of being truncated, while the sample/range indicator remains visible.

## Qualification focus

Upgrade from rc.15 and confirm:

- Administration → Settings shows `CPU Limit` for editable and saved resource-profile values;
- resource-default helper copy makes it clear CPU limits are not reserved CPU;
- host capacity still reports physical CPU cores separately from project CPU limits;
- Projects dashboard CPU helper text is fully readable at narrow card widths instead of ending in an ellipsis;
- the sample/range label such as `1 sample` remains visible beside wrapped helper text;
- frontend unit tests, Svelte/type checks, production build, and rootful Podman compatibility remain green;
- no backend resource-limit or quota semantics change from rc.15.
