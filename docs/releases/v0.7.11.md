# MyPaaS v0.7.11

**Release type:** Stable patch release  
**Release date:** 2026-10-02  
**Release tag:** `v0.7.11`

`v0.7.11` adds a restrained diagonal hatch texture to the Host resources area fills.

## Highlights

### Subtle diagonal hatch

- Memory, CPU, and Network area fills now include a thin diagonal hatch overlay.
- All three series use the same hatch direction and spacing for a consistent observability-style texture.
- Hatch spacing is 9 units with a `0.5` stroke and `0.10` opacity.

### Lighter semantic fills

- The underlying area gradients were reduced so the hatch texture remains subtle.
- Existing thin `1.35px` series strokes are preserved.
- The 6px vertical plot headroom remains unchanged.
- Storage remains flat and unhatched.
- Telemetry collection, history semantics, scales, and chart geometry are unchanged.
