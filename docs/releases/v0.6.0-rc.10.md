# MyPaaS v0.6.0-rc.10

## Included changes

- Moves the update availability banner to the top-right below the header.
- Keeps System Update progress fills high-contrast in dark mode and uses a moving sheen instead of opacity pulsing.
- Fixes Chromium workspace over-height by making the authenticated shell the single viewport-height owner while normal routes size to their content.
- Keeps loader-only viewport reservation with a `100dvh` / `100vh` fallback.

## Qualification focus

Install rc.10 from rc.9 and confirm:

- the update banner appears below the header on the right;
- active update progress remains clearly visible in dark mode;
- Chromium `/projects` no longer produces the oversized blank page or phantom vertical scroll;
- Firefox route sizing remains content-sized;
- update discovery, reconnect, and completion behavior remain unchanged.
