# MyPaaS v0.6.0-rc.7

## Included changes

- MCP agent icons are now a static overlapping row instead of a continuous marquee.
- Agent marks stay monochrome by default and reveal LobeHub color variants on hover or keyboard focus, with a safe fallback when a color asset is unavailable.
- Release discovery now starts automatically after owner authentication resolves, so the bell badge no longer depends on opening the bell first.
- A compact per-release update banner appears when a new qualified release is available and can be dismissed without hiding the bell indicator.
- Stable release discovery now uses GitHub's latest stable release endpoint, matching the host updater semantics.
- System Update progress uses faster active polling and transform-based stage transitions with a subtle active pulse while preserving real host phase milestones.

## Qualification focus

This release qualifies the notification and update UX changes merged in PR #271. Install rc.7 first, then use the next release to verify automatic release discovery, update banner visibility, progress animation, reconnect behavior, and the MCP agent hover treatment in a real updater run.
