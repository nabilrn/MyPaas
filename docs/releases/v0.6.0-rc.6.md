# MyPaaS v0.6.0-rc.6

## MCP agent experience

- Refreshes the Administration MCP page around agent-first workflows.
- Uses LobeHub's maintained static SVG icon catalog for coding-agent branding without adding a React runtime to the Svelte dashboard.
- Replaces the fixed client grid with an overlapping circular marquee inspired by the new MCP visual direction.
- Pauses the marquee on hover, lifts the focused agent mark, and shows the agent name in a tooltip.
- Preserves a reduced-motion fallback for users who disable animation.
- Renames the section from supported clients to agent-friendly wording and aligns the connection copy around agents.

## Qualification focus

This prerelease is intended to validate the new MCP agent marquee in a real dashboard update from v0.6.0-rc.5, while also exercising the System Update progress UI, navigation/reload guard, reconnect behavior, notification indicator, and final installed-state confirmation.
