# MyPaaS v0.6.0-rc.14

## Included changes

- Fixes Create Project submission for static applications using the `0.01` CPU Static/no-runtime profile floor.
- Aligns the Create Project CPU input constraint with the platform resource-profile floor so native browser form validation no longer blocks project creation with `An invalid form control is not focusable`.
- Allows CPU values to be edited in `0.01`-core increments in Create Project Advanced settings.
- Keeps backend resource-profile behavior and non-static deployment resource defaults unchanged.

## Qualification focus

Upgrade from rc.13 and confirm:

- a static project using the configured `0.01` CPU default can be created successfully;
- Create Project no longer emits `An invalid form control is not focusable`;
- the Advanced settings CPU field accepts `0.01`;
- Dockerfile, Compose, registry-image, and existing project resource behavior remain unchanged;
- frontend unit tests, Svelte checks, and production build remain green.
