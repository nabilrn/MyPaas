# MyPaaS v0.6.0-rc.5

## System Update UX

- Replaces the vertical updater timeline with a compact stage-based progress bar.
- Shows release highlights directly from qualified GitHub release notes.
- Adds clearer update-in-progress guidance so users know not to refresh or restart the host manually.
- Guards internal navigation while an update is running and relies on the browser's native unload confirmation for full-page reloads or tab closes.
- Strengthens the notification bell indicator so available updates are visible without opening the bell first.
- Refines release wording in the dashboard from published releases to qualified releases.

## Qualification focus

This prerelease is intended to validate the complete dashboard update experience from notification discovery through the dedicated System Update page, live progress, reconnect behavior, reload protection, and final installed-state confirmation.
