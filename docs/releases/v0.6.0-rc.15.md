# MyPaaS v0.6.0-rc.15

## Included changes

- Treats project CPU values as shared runtime ceilings instead of reserved/dedicated CPU capacity, and aligns host statistics plus frontend capacity presentation with that shared-CPU model.
- Excludes static/no-runtime projects from runtime CPU/RAM quota accounting while preserving the configurable Static profile floor at `0.01` CPU.
- Makes SQLC generation reproducible with a pinned `sqlc` v1.31.1 toolchain, committed generated-state checks, and synchronized project/user query contracts.
- Consolidates Podman qualification into the primary CI workflow, executes qualification harness unit tests there, and removes orphaned Podman CI/bootstrap helpers.
- Renames the old benchmark harness to `qualification/` and removes obsolete benchmark-only code so validation is framed around platform contracts rather than universal performance claims.
- Removes unused frontend dependencies, dead audit/agent assets, unused install environment keys, and other stale repository tooling/documentation residue.
- Aligns current product/engineering documentation and ADR numbering with the implemented product surface.

## Qualification focus

Upgrade from rc.14 and confirm:

- existing container-backed projects continue to run with CPU limits behaving as shared ceilings rather than reserved host capacity;
- host/admin CPU capacity and quota views no longer imply that configured project CPU limits are statically reserved;
- static projects do not consume runtime CPU/RAM quota and continue to support the `0.01` CPU Static/no-runtime profile floor;
- Dockerfile, Compose, static, and registry-image project lifecycle behavior remains unchanged;
- project settings and Administration resource values remain readable and writable after restart;
- SQLC generated state is clean and reproducible from the pinned toolchain;
- Docker and rootful Podman qualification remain green in the consolidated CI workflow;
- production Compose, routing, dashboard, API, and existing project data remain unchanged by repository cleanup work.
