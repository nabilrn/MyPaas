# MyPaaS v0.6.0-rc.3

Release candidate focused on validating the new System Update experience before the final v0.6.0 release.

## Highlights

- Dedicated Administration → System update workspace.
- Server-rendered initial updater state with live polling during an update.
- Real updater phases for release resolution, artifact checks, preflight, apply, verification, completion, failure, and rollback.
- Release bell now acts as a notification/entry point instead of executing the update inline.
- Update progress survives a temporary dashboard restart and reconnects automatically.
- Browser reloads once after a confirmed successful update so the new dashboard bundle is loaded without a manual refresh.
- Stale success/failure state from an older release no longer appears as the state of a newly available release.
- Atomic updater status writes hardened for custom status-file locations.

## Qualification goal

Use this prerelease to bootstrap an existing v0.6.0-rc.2 installation onto the new updater UI. The end-to-end progress UX itself should be qualified with a subsequent prerelease transition before publishing v0.6.0 final.
