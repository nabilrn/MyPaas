# MyPaaS v0.7.2

**Release type:** Stable patch release  
**Release date:** 2026-10-01  
**Release tag:** `v0.7.2`

`v0.7.2` is a focused UI patch for the host-resource telemetry surface introduced in `v0.7.1`.

## Highlights

### Host resource telemetry readability

- RAM, CPU, and network remain combined in one compact shared chart.
- Each telemetry series now has a subtle semantic gradient fill beneath its line, restoring visual depth without turning the chart into separate cards.
- The chart exposes a clear 0–100% reference for RAM and CPU and an adaptive rate range for network traffic.
- The horizontal timeline now communicates Earlier → Now, while hover/focus inspection includes the exact sample time.
- Tooltip positioning follows the same inset plot coordinate system as pointer selection.
- Memory, CPU, and network visibility toggles remain independent and are exposed as an accessible control group.

### Storage capacity context

- Storage remains a persistent horizontal capacity bar rather than a time-series.
- The storage strip now labels total usage, percent used, and available capacity directly around the bar so the fill is not ambiguous.

### UI quality and regression coverage

- The merged chart is more compact while preserving readable data strokes and quiet grid lines.
- Responsive assertions were updated for the refined chart height.
- Tests now cover the semantic area fills, scale/time context, inset tooltip contract, accessibility grouping, storage context, isolated telemetry samples, and telemetry outage gaps.
