# MyPaas v0.6.0-rc.1

**Release type:** Prerelease / release-candidate qualification  
**Target commit:** `a31ab5f1496153ec58e09a290b37b833f86d5f1f`

This release candidate exists to qualify the new release-aware notification and manual updater flow before publishing `v0.6.0`.

## Included changes

- Release-aware updater defaults production installs to published GitHub Releases instead of arbitrary `main` commits.
- Owner notification bell can surface a newer published release and the host updater's actual status.
- Update status distinguishes checking, updating, succeeded, failed, rolled back, and blocked states.
- Frontend-only releases preserve the dashboard-only fast path while aliasing the unchanged API image to the release SHA.
- Administration → General removes the duplicate horizontal separator above the page workspace.

## Qualification goal

A VM intentionally left on the previous build should detect `v0.6.0-rc.1` in the dashboard, offer the manual update action, apply the exact release target, and report the final updater state without relying on API restart guessing.

This prerelease is for updater qualification, not the final `v0.6.0` release.
