# MyPaaS v0.7.10

**Release type:** Stable patch release  
**Release date:** 2026-10-02  
**Release tag:** `v0.7.10`

`v0.7.10` refines the Host resources chart for a thinner, more minimal visual treatment while preserving the current telemetry behavior.

## Highlights

### Thinner chart rendering

- Resource series strokes reduced from `1.85px` to `1.35px`.
- Grid strokes reduced from `0.7px` to `0.5px`.
- Hover guide reduced from `0.8px` to `0.6px`.
- Isolated sample points reduced from radius `1.9` to `1.5`.
- Hover sample points reduced from radius `2.3` to `1.9`.

### Edge visibility preserved

- The existing 6px vertical plot headroom remains in place.
- 0% / 100% percentage extrema and adaptive Network extrema stay fully visible instead of being clipped at the SVG boundary.
- Telemetry collection, history semantics, colors, scales, and layout are unchanged.
