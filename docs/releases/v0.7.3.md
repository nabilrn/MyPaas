# MyPaaS v0.7.3

**Release type:** Stable patch release  
**Release date:** 2026-10-01  
**Release tag:** `v0.7.3`

`v0.7.3` refines the host-resource monitoring workspace introduced across the `v0.7.x` stable line and makes repository CI more selective for frontend-only changes.

## Highlights

### Chart-first Host resources workspace

- Host resources now use a desktop **75/25 split**:
  - the left side is dedicated to the merged Memory / CPU / Network history chart plus Storage capacity;
  - the right side keeps RAM, CPU, Network, and Storage as stacked live summaries.
- The chart area is taller and retains semantic area fills so overlapping telemetry remains readable.
- Storage remains a capacity strip directly below the chart instead of pretending to be a time-series.
- Narrower layouts collapse to one column while preserving the same information hierarchy.

### Telemetry warm-up and unavailable states

- The history chart waits for **8 telemetry samples** before rendering, avoiding sparse first-load visuals.
- While telemetry history is warming up, the chart area keeps its final dimensions and shows a compact collection-progress state.
- Live summary values remain available during warm-up.
- Memory / CPU / Network visibility controls stay disabled until the chart is ready.
- Missing mypaas-statd telemetry now shows a stable **History unavailable** state instead of an impossible `0/8` warm-up.
- Polling progress is no longer exposed as a continuously updating live region for assistive technology.

### CI relevance improvements

- CI now classifies changed paths into explicit frontend, backend, deployment, Podman, and public/operator-contract requirements.
- Ordinary frontend UI changes run frontend checks without spending time on backend, deployment, Podman, or public-contract jobs.
- Production Caddy, release-publishing, Docker-publishing, and public-contract checker changes still route through their relevant qualification suites.
- The guarded release workflow is scoped to release-note PRs instead of creating skipped release jobs for normal feature work.
