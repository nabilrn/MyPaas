# MyPaaS v0.6.0-rc.4

Release candidate for end-to-end qualification of the dedicated System Update experience introduced in RC3.

## Qualification focus

- Detect the newer release from an existing v0.6.0-rc.3 installation.
- Enter the dedicated Administration → System update workspace from the notification bell.
- Queue the update from that page and observe real host-updater phases.
- Keep the progress view usable while the control plane/dashboard temporarily restarts.
- Reconnect to updater status automatically after restart.
- Verify the final target revision and reload the dashboard automatically after confirmed success.
- Finish with v0.6.0-rc.4 reported as the installed release without a manual browser refresh.

## Included changes

- System update navigation copy now describes qualified MyPaaS releases, matching the exact-SHA release gate.
- Frontend-only GHCR publishing no longer assumes the immediate parent already has an immutable API alias. Safe ancestor reuse is validated across the effective diff, with a fail-safe API build fallback when reuse cannot be proven.

This prerelease is for qualification before v0.6.0 final.
